5. What is a closure?
Ans : 
A closure is a **function that remembers and can access variables from its lexical scope, even after that outer function has finished executing.
In simpler terms:
Closures let a function "remember" variables from the place where it was created.
function outerFunction() {
  let message = "Hello from outer!";

  function innerFunction() {
    console.log(message);  // Accesses message even after outerFunction has finished
  }

  return innerFunction;
}

const myClosure = outerFunction(); // outerFunction executes
myClosure(); // Logs: Hello from outer!


6. What is hoisting?
Ans : 
✅ What is Hoisting in JavaScript?
Hoisting is JavaScript’s default behavior of moving declarations to the top of their scope (global or function) before code execution.

🔍 In Other Words:
When your code runs, JavaScript "hoists" variable and function declarations (not initializations) to the top of the scope.
Example : 
🧪 Example 1: Variable Hoisting with var
console.log(x); // undefined (NOT ReferenceError)
var x = 5;

JavaScript internally treats it like:
var x;          // declaration hoisted
console.log(x); // undefined
x = 5;          // initialization remains in place

8. What are JavaScript prototypes?
Ans:  In JavaScript, every object has a hidden internal property called [[Prototype]], which refers to another object — known as its prototype.
This is the foundation of prototypal inheritance — where objects inherit properties and methods from other objects.
📌 Why Are Prototypes Important?
Prototypes allow:
Object inheritance without classes
Shared methods (for memory efficiency)
The use of built-in methods like .toString(), .hasOwnProperty(), etc.
Exa :
function Person(name) {
  this.name = name;
}
// Adding a method to the prototype
Person.prototype.sayHello = function () {
  console.log(`Hello, my name is ${this.name}`);
};

const p1 = new Person("Alice");
const p2 = new Person("Bob");

p1.sayHello(); // Hello, my name is Alice
p2.sayHello(); // Hello, my name is Bob

11. What is a promise?
Ans : 
A Promise in JavaScript is an object that represents the eventual completion (or failure) of an asynchronous operation, and lets you attach callbacks to handle the result.
📦 Think of it like:
“A placeholder for a value that’s not available yet, but will be in the future.”
📌 States of a Promise
State	                 Description
Pending: 	    Initial state, neither fulfilled nor rejected
Fulfilled:	     Operation completed successfully
Rejected: 	     Operation failed with an error
🧠 Promises (Old Way)
Before async/await, we used Promises with .then() and .catch().
function getUserData() {
  fetch('https://jsonplaceholder.typicode.com/users/1')
    .then(response => response.json())
    .then(data => console.log("User data:", data))
    .catch(err => console.log("Error:", err));
}

14. What are JavaScript modules?
Ans : JavaScript modules are reusable pieces of code that are split across files to keep your codebase organized, maintainable, and easy to scale. Modules let you export and import variables, functions, classes, etc., between files.

🧱 Why Use Modules?
Without modules, JavaScript apps quickly become messy as all code lives in one global space. Modules allow:

Code reusability ✅
Separation of concerns ✅
Avoiding global scope pollution ✅
Easier testing and maintenance ✅

33. What is the `spread` (...) operator?
Ans :The spread operator (...) is a powerful ES6 feature that expands (or "spreads out") iterables like arrays, objects, or strings into individual elements.

It’s commonly used for:
Copying arrays/objects
Merging arrays/objects
Passing multiple arguments to functions
🔹 1. Spread with Arrays
A.✅ Copy an Array
const original = [1, 2, 3];
const copy = [...original];
console.log(copy); // [1, 2, 3]
B.✅ Merge Arrays
const arr1 = [1, 2];
const arr2 = [3, 4];
const merged = [...arr1, ...arr2];
console.log(merged); // [1, 2, 3, 4]
C.✅ Add Elements to an Array
const numbers = [2, 3, 4];
const newNumbers = [1, ...numbers, 5];

console.log(newNumbers); // [1, 2, 3, 4, 5]

🔹 2. Spread with Objects
A. ✅ Clone an Object
const user = { name: 'Niraj', age: 25 };
const clonedUser = { ...user };

console.log(clonedUser); // { name: 'Niraj', age: 25 }

38. How do you create a class in JavaScript?
Ans : In JavaScript, you can create a class using the class keyword introduced in ES6 (ECMAScript 2015). A class is essentially a blueprint for creating objects with shared properties and methods.
🔹 Basic Syntax:
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  // Method
  greet() {
    console.log(`Hello, my name is ${this.name} and I am ${this.age} years old.`);
  }
}
🔹 Create an Object (Instance)
const person1 = new Person("Niraj", 25);
person1.greet(); // Output: Hello, my name is Niraj and I am 25 years old.
🔹 Static Methods
Static methods are called on the class itself, not on instances:
class MathUtil {
  static add(a, b) {
    return a + b;
  }
}

console.log(MathUtil.add(5, 3)); // 8


39. What is destructuring in JavaScript?
Ans : Array destructuring lets you assign elements of an array to variables in a single statement.
const colors = ['red', 'green', 'blue'];
const [firstColor, secondColor] = colors;
console.log(firstColor); // Output: 'red'
console.log(secondColor); // Output: 'green'


Object destructuring allows you to extract properties from objects into variables.
const person = { name: 'Alice', age: 25 };
const { name, age } = person;
console.log(name); // 'Alice'
console.log(age);  // 25
