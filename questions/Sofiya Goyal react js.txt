Q. What is Hoisting in JavaScript?
Ans :
🔍 Key Points:
1.Only declarations (not initializations) are hoisted.
2.var, function declarations, and class declarations are hoisted.
3.let and const are also hoisted but stay in a "Temporal Dead Zone" (TDZ)", so using them before declaration causes a ReferenceError.

Example : function Hoisting
greet(); // ✅ Works
function greet() {
    console.log("Hello!");
}

Q. What is prototype in js ?
Ans :
Every JavaScript function (including constructors) has a built-in property called .prototype. This property is an object that is shared among all instances created using that function.
Example :
const animal = {
    speak() {
        console.log("Animal sound");
    }
};
const dog = Object.create(animal);
dog.speak(); // Animal sound

Q. What is react lifecycle?
Ans : 🔄 React Lifecycle Explained (for Class Components)
      React lifecycle methods are hooks that allow you to run code at particular times in a component's life (creation, updating, and destruction).	  
	    
📦 Three Main Phases
1. Mounting – when the component is being created and inserted into the DOM.
2. Updating – when the component is being re-rendered due to state/prop changes.
3. Unmounting – when the component is removed from the DOM.	 

🟩 1. Mounting Phase
| Method                              | Purpose                                                |
| ----------------------------------- | ------------------------------------------------------ |
| `constructor()`                     | Initialize state and bind methods.                     |
| `static getDerivedStateFromProps()` | Update state from props before render (rarely used).   |
| `render()`                          | Returns JSX. Required.                                 |
| `componentDidMount()`               | Runs once after the first render; great for API calls. |

✅ Typical Use: API fetch, setting timers, subscriptions.

🔄 2. Updating Phase
Occurs when:
this.setState() is called
Parent re-renders and passes new props 

| Method                              | Purpose                                                                |
| ----------------------------------- | ---------------------------------------------------------------------- |
| `static getDerivedStateFromProps()` | Same as in mounting.                                                   |
| `shouldComponentUpdate()`           | Determines whether to re-render.                                       |
| `render()`                          | Re-render with new data.                                               |
| `getSnapshotBeforeUpdate()`         | Capture values (like scroll position) before DOM is updated.           |
| `componentDidUpdate()`              | Run code after the component updates. Good for DOM or network updates. |

✅ Typical Use: Responding to prop changes, DOM measurements, side effects.

🟥 3. Unmounting Phase
| Method                   | Purpose                                                           |
| ------------------------ | ----------------------------------------------------------------- |
| `componentWillUnmount()` | Cleanup work like clearing timers, cancelling subscriptions, etc. |
✅ Typical Use: Avoid memory leaks, cleanup side effects.

📜 Full Lifecycle Flow
Mounting:
constructor → getDerivedStateFromProps → render → componentDidMount

Updating:
getDerivedStateFromProps → shouldComponentUpdate → render → getSnapshotBeforeUpdate → componentDidUpdate

Unmounting:
componentWillUnmount

✅ React Hooks Equivalent (for Functional Components)
| Class Component        | Functional Component (Hooks)                |
| ---------------------- | ------------------------------------------- |
| `componentDidMount`    | `useEffect(() => {}, [])`                   |
| `componentDidUpdate`   | `useEffect(() => {…}, [deps])`              |
| `componentWillUnmount` | `useEffect(() => { return () => {}; }, [])` |
📌 Example:
import React, { Component } from 'react';

class MyComponent extends Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
    console.log("Constructor");
  }

  componentDidMount() {
    console.log("Component Mounted");
  }

  componentDidUpdate(prevProps, prevState) {
    console.log("Component Updated");
  }

  componentWillUnmount() {
    console.log("Component Will Unmount");
  }

  render() {
    return (
      <div>
        <p>Count: {this.state.count}</p>
        <button onClick={() => this.setState({ count: this.state.count + 1 })}>
          Increment
        </button>
      </div>
    );
  }
}
